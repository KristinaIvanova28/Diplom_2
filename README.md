## Реализованные сценарии

#### Создание пользователя:
- создать уникального пользователя;
- создать пользователя, который уже зарегистрирован;
- создать пользователя и не заполнить одно из обязательных полей.

#### Логин пользователя:
- вход под существующим пользователем;
- вход с неверным логином и паролем.

#### Создание заказа:
- создать заказ с авторизацией;
- создать заказ без авторизации;
- создать заказ с ингредиентами;
- создать заказ с без ингредиентов;
- создать заказ с неверным хешем ингредиентов.

## Запуск автотестов

#### Установка зависимостей

> `$ pip install -r requirements.txt`

---
## Генерация отчёта

#### Запуск тестов с генерацией результатов

> `$ pytest --alluredir=allure_results`

#### Генерация HTML-отчёта

> `$ allure serve allure_results`
